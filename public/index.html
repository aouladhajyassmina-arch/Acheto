Questions fréquentes

Les réponses utiles pour acheter et vendre en toute confiance sur Acheto.

Comment déposer une annonce ?

Créez un compte, appuyez sur « Déposer », remplissez les informations et ajoutez une photo claire. Vérifiez l’aperçu puis envoyez votre annonce.

Comment savoir si mon annonce est validée ?

Ouvrez la page « Suivi ». Une annonce en vérification attend l’examen de l’équipe ; une annonce validée devient visible aux acheteurs. Le suivi de démonstration est enregistré sur cet appareil.

Pourquoi mon annonce a-t-elle été refusée ?

Vérifiez que le produit est décrit honnêtement, que le prix et les coordonnées sont corrects et que la photo montre bien l’article proposé. Corrigez l’annonce avant de la renvoyer.

Comment contacter un vendeur ?

Ouvrez l’annonce puis choisissez « Appeler le vendeur » ou « Envoyer un message ». Convenez d’un lieu sûr pour voir l’article.

Comment retrouver une annonce aimée ?

Touchez le cœur sur une annonce. Elle sera conservée dans « Favoris » sur votre appareil.

Est-ce que je dois payer pour publier ?

La publication standard est gratuite. Ne partagez jamais votre code bancaire ou un code reçu par SMS avec un interlocuteur.
